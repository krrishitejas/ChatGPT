# ChatGPT Repository

This repository contains a basic website for **Airloper**, a company focused on AI-powered autonomous infrastructure systems. The website files live in the `airloper/` directory and include:

- `index.html` – main page with business overview and product ecosystem
- `style.css` – simple responsive styles
- `script.js` – small JavaScript for dynamic copyright year

To view the site locally, open `airloper/index.html` in your browser.
